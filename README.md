# my_notes
Notebooks usando Astropop e outras ferramentas astronômicas

Aperture and differential photometry: This notebook use ASTROPOP to perform aperture and differential photometry. To do this, some previous steps are necessary, as to have the images corrected by bias and flat, and to have the stack of the images. The code will identify the sources, the shifts between the images and perfor the photometry. This specif case is the photometry for a host star Hats-24 and their exoplanet Hats-24b.
